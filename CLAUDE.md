# CLAUDE.md - Regras de Desenvolvimento

Estas regras devem ser seguidas em todas as sessões de desenvolvimento com Claude Code neste projeto.

## Regras de Processo

1. **Descrever antes de codar.** Antes de escrever qualquer código, descreva a abordagem proposta e aguarde aprovação. Sempre faça perguntas de esclarecimento se os requisitos forem ambíguos.

2. **Limitar escopo por tarefa.** Se uma tarefa exige alterações em mais de 3 arquivos, pare e quebre em tarefas menores primeiro.

3. **Listar riscos após codar.** Depois de escrever código, liste o que pode quebrar e sugira testes para cobrir.

4. **Bug = teste primeiro.** Quando houver um bug, comece escrevendo um teste que o reproduz. Depois corrija até o teste passar.

5. **Correções viram regras.** Toda vez que o usuário corrigir o Claude, adicione uma nova regra a este arquivo para que o erro não se repita.
